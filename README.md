# S1-Response-Varying-PNS-PW
Repository to accompany paper "Peripheral nerve stimulation reliably evokes touch after spinal cord injury and creates robust onset transients in somatosensory cortex"

To run the code, add the helper functions folder and download the following packages that aid with figure generation:

ChartsWithCharles: https://github.com/CMGreenspon/ChartsWithCharles.git
ScientificColorMaps: https://zenodo.org/records/8409685
